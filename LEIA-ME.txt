COMO ABRIR NO VS CODE
1. Extraia o arquivo ZIP para uma pasta do computador.
2. Abra o VS Code.
3. Clique em Arquivo > Abrir Pasta e escolha a pasta beatriz-links-site.
4. Abra o arquivo index.html.
5. Para visualizar, clique duas vezes no index.html pelo Explorador de Arquivos, ou instale a extensão Live Server no VS Code e clique em Go Live.

PUBLICAR GRATUITAMENTE COM GITHUB PAGES
1. Crie/login em https://github.com/.
2. Clique em New repository e dê um nome, por exemplo: beatriz-andrade-links.
3. Escolha Public e crie o repositório.
4. Dentro do repositório, clique em Add file > Upload files.
5. Envie os três arquivos (index.html, style.css e beatriz.jpg) — envie os arquivos, não apenas a pasta ZIP.
6. Clique em Commit changes.
7. Abra Settings > Pages.
8. Em Build and deployment, escolha Deploy from a branch.
9. Selecione a branch main e a pasta /(root), depois clique em Save.
10. Aguarde alguns minutos e volte à seção Pages. O endereço do site aparecerá ali, normalmente como https://SEU-USUARIO.github.io/beatriz-andrade-links/.
